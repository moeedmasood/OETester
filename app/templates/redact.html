Custom Redaction Rules

Define a format template or regular expression describing the data to redact. Format templates use 9 = digit, A = uppercase letter, a = lowercase letter, X = any letter, * = any letter/digit; any other character is matched literally. E.g. 999 999 999 for a 9-digit TFN written with spaces. Use "Check" to sense-check a rule before submitting - overly generic patterns (e.g. a single wildcard digit) are rejected.
